# Portfolio static site

The German and English portfolio is generated by `src/build.mjs` from
`src/content.json`, with static assets copied from `public/`. The Pages workflow
in `../.github/workflows/pages.yml` owns production deployment from `main`.
The separate `services/` implementation is outside this build.

## Verification

Run `node --test site/tests/*.test.mjs` from the repository root. The public-build
regression test checks both language versions, generated metadata, project links,
legal pages and copied assets. It prevents the retired Somnia promotion or its
old redirect from reappearing in the portfolio output. Somnia's independent
repository, site and subdomain are not modified by this removal.

A temporary local build can be generated with:

```sh
mkdir -p /tmp/portfolio-preview
cp -r site/public/. /tmp/portfolio-preview/
node site/src/build.mjs /tmp/portfolio-preview
```

For full visual fidelity, copy the pinned fonts and animation dependencies as
specified by the Pages workflow. No deployment or analytics credentials are
needed for the static build or regression test.
